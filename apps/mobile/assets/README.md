# Assets provisórios

Os ícones deste scaffold são marcadores AVIORA preto/dourado gerados para permitir build e validação da fundação.

Antes de qualquer distribuição externa, substitua-os por exportações oficiais da matriz visual escolhida — águia dourada em voo rasante dentro da bússola circular, com candles financeiros — respeitando margens e requisitos da Apple/Google.

A substituição de asset não autoriza alterar a marca, o nome ou os identificadores de loja sem aprovação.
