MENTORIA BLACK — GESTÃO FINANCEIRA V10

Arquivos da V10
- index.html
- sw.js
- README.txt

Principais melhorias
- Nova identidade visual MB em SVG vetorial, com coroa, monograma, moldura e filigrana.
- MENTORIA BLACK + GESTÃO FINANCEIRA mantidos no cabeçalho.
- Ano de 2000 a 2100.
- Planejamento separado por mês/ano.
- Lazer e Conhecimento separados.
- Distribuição planejada usa as cores das categorias.
- Gráficos de despesas por categoria em colunas, com valor + percentual acima das barras.
- Planejado x realizado detalhado por categoria.
- Resumo de cartões de crédito por período.
- Reserva de emergência identificável por meta, conta ou ativo com Reserva/Emergência/Caixinha no nome.
- Parcelamento pelo valor total, quantidade de parcelas e mês inicial de pagamento.
- Última parcela ajusta centavos para fechar exatamente o valor total.
- Despesa fixa independente de parcelamento e vinculada a recorrência mensal.
- Categorias/subcategorias editáveis.
- Proteção contra exclusão de registros com dependências.
- Service worker com cache V10 para reduzir permanência de versão antiga.

Instalação
1. Substitua index.html no repositório.
2. Substitua sw.js.
3. Substitua README.txt se desejar.
4. Não altere as tabelas do Supabase para instalar a V10.
5. Aguarde o GitHub Pages publicar.
6. No iPhone, recarregue a página; se estiver instalada como PWA e continuar mostrando a versão anterior, feche e abra novamente.

Observação técnica
A V10 usa a base funcional V9 como referência e aplica uma camada visual/robusta sobre ela, preservando a autenticação e a persistência existentes.
