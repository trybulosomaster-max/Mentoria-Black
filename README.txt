MENTORIA BLACK — V20

ALTERAÇÃO PRINCIPAL
- A tela Lançamentos mantém a opção "Todos os meses".
- Foi adicionada a seleção "Mês", com os meses/anos existentes nos lançamentos.
- "Todos os meses" mostra novamente a lista completa.
- Ao selecionar um mês, a lista passa a mostrar somente aquele período.
- O período usa Ano-Mês para evitar misturar, por exemplo, agosto/2026 com agosto/2027.
- Foi incluído um resumo do período com quantidade de lançamentos, receitas/resgates e saídas.
- A V20 preserva as correções da V19.1, inclusive a separação de categorias por tipo e a lógica de data de compra/data da fatura.

PUBLICAÇÃO
1. Renomeie index-v20.html para index.html.
2. Renomeie sw-v20.js para sw.js.
3. Publique os dois arquivos no GitHub/hosting.
4. Abra o aplicativo novamente. O Service Worker agora usa o cache mentoria-black-v20.
